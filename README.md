# Программа анализа телеметрии и фиксации инцидентов

---
## Этап 1

### 1. Назначение программы
Программа предназначена для автоматизированной обработки и анализа телеметрических данных. Она выполняет парсинг входных записей, рассчитывает ппоказатели динамики для компонентов, определяет их текущее состояние (Normal или Alert) и регистрирует инциденты на основе заданного условия с последующим расчетом статистики

### 2. Описание варианта
* **Вариант:** №20 (базовый)
* **Анализируемый компонент:** `A1`
* **Производный показатель:** Темп роста показателя компонента
* **Критерий ALERT:** Превышение модулем темпа роста порогового значения 0.15
* **Критерий инцидента:** Нахождение большинства компонентов системы в состоянии ALERT

### 3. Описание инфраструктурных компонентов

### 4. Формат исходных данных
* **Код компонента:** А1
* **Разделитель элементов:** Точка с запятой (`;`)
* **Порядок данных:** `время -> компонент -> значение`
* **запись:** Несколько последовательных измерений в одной записи
* **Временная модель:** `T` — порядковый номер отсчёта (целое число)
* **Пример строки данных:** `1;A1;24.5;2;A1;25.1;3;A1;26.0`
